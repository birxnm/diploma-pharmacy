# frontend

_PHA2-4 · Last updated: 2026-10-14_

Web interface of PharmaStock built with Vue 3, Vite, TypeScript, Vue Router, Pinia and Chart.js: dashboards, item pages with consumption history and forecast, prioritised shortage-risk list and in-app notifications. Owner: Birkhanym Kazhymukhamet.
The Vite scaffold (`package.json`, `vite.config.ts`, `index.html`, `src/`) will be added when work on the main screens starts; until then the agreed screens are shown as static mockups in `../prototype/`.
