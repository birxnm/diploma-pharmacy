# docs/diagrams

_PHA2-4 · Last updated: 2026-10-14_

Architecture, data-flow, database (ER) and sequence diagrams of PharmaStock. Sources are Mermaid files in `src/*.mmd`; rendered copies for the thesis and presentations are stored in `export/*.svg`.
Edit the `.mmd` source first and re-export the SVG in the same pull request. Markdown documents in `docs/` embed the Mermaid source, which GitHub renders directly.
